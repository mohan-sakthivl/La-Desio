# 🍰 LA DESIO — Luxury Italian Patisserie E-Commerce

> *"Where Cravings Become Creations."*

An e-commerce web platform for **LA DESIO**, an artisanal Italian-inspired luxury dessert brand combining handcrafted signature patisserie, interactive bespoke dessert creation, and an ingredient-conscious **Desio Natural** collection.

---

## ✨ Features

- **🏛️ Signature Patisserie Catalog**: Curated Italian desserts (*Velvet Noir*, *Pistachio Royale*, *Berry Élan*, *Caramel Étoile*, *Tiramisu Classico*, *Strawberry Rosé*) with dynamic modifiers, serving specs, and allergen indicators.
- **🌿 Desio Natural Collection**: Mindful ingredient-conscious desserts sweetened with Medjool dates, Alfonso mango purée, wild forest honey, and high-percentage Peruvian cacao without artificial sweeteners.
- **✨ 6-Step Bespoke Dessert Studio**: Live interactive custom dessert builder with dynamic visual preview canvas, calorie/allergen calculations, and real-time INR price breakdown.
- **🎁 Luxury Gifting & Hampers**: Ribbon-sealed presentation chests, couple's collections, handwritten calligraphy cards, and scheduled celebration delivery.
- **💖 Slideover Wishlist & Shopping Bag**: Real-time persistent state, free delivery progress meter (₹999 threshold), discount promo codes (`LADESIO10`, `ROYALE20`, `SWEETDESIO`), and bulk transfer actions.
- **💳 Multi-Step Indian Checkout**: Full address management, UPI QR code generation (GPay, PhonePe, Paytm, CRED), realistic card interface, and Indian Net Banking across major institutions.
- **👑 La Desio Privé Club**: Tiered loyalty reward program (Amore, Élite, Royale) tracking spend points and member privileges.

---

## 🛠️ Tech Stack

- **HTML5 & CSS3** (Vanilla ES Modules architecture)
- **Tailwind CSS** (Custom Italian luxury color palette & typography tokens)
- **Google Fonts** (*Playfair Display*, *Cormorant Garamond*, *Alex Brush*, *Inter*)
- **LocalStorage API** (Persistent Cart, Wishlist, and Privé loyalty profiles)

---

## 🚀 Quick Start

1. Clone the repository:
   ```bash
   git clone <REPO_URL>
   cd "LA Desio"
   ```

2. Run a local web server (Python 3):
   ```bash
   python -m http.server 4173
   ```

3. Open in your browser:
   ```
   http://localhost:4173
   ```
